# Fabric Mods for evidence-epic.gl.joinmc.link

## Requirements
- Minecraft 1.21.1
- Fabric Loader: https://fabricmc.net/use/installer/

## Install
1. Install Fabric Loader for 1.21.1 (link above)
2. Download all 3 .jar files from this repo
3. Drop them into your mods folder:
   - Windows: %appdata%\.minecraft\mods\
   - Mac: ~/Library/Application Support/minecraft/mods/
4. Launch Minecraft with the Fabric 1.21.1 profile
5. Join: evidence-epic.gl.joinmc.link
